# Changelog

All notable changes to PRK Companion are documented here.

## [0.25.0] - 2026-08-20

### Added

- Persistent back, forward, and refresh controls above the website tabs.
- Address/search bar access while browsing any saved resource.
- PRK DB (`prk.gg`) quick link beside PRKTools.
- High-resolution embedded refresh icon with DPI-aware rendering.

### Changed

- Reduced horizontal padding inside link buttons while preserving clear spacing between them.
- Matched Settings and Quit button spacing to the resource links and kept them right-aligned.
- Added hover and pressed feedback to the GO button.
- Updated README features, controls, download link, and screenshots.

## [0.24.2] - 2026-07-29

- First stable public release with the fullscreen overlay, persistent resource tabs, calculator, configurable hotkey, opacity, overlay scale, Settings, and Quit controls.
